## Общая цель — один законченный сценарий

**Кандидат → адаптивная анкета → уточнение → объяснимая рекомендация → сохранённая строка в Google Sheets.**

Человек видит причину рекомендаций и вопросы к интервью. Оценка куратора по истории 0–3 используется для проверки качества, не заменяет критерий полезности рекомендаций.
