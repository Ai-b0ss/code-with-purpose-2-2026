## Решения до RAG-merge

1. **Вывод:** кандидат получает подтверждение и свой выбор; служебная аналитика остаётся у куратора. Возврат критериев/балла на публичный экран не считается согласованным.
2. **Рубрика:** рекомендации с score=null сохраняются. Шесть критериев, веса 25/20/20/15/10/10 и шкала 1–3 с шагом 0,25 — предложение Саши, не историческая калибровка. Нужна экспертная проверка до замены main.
3. **Нагрузка:** согласовать нейтральную трактовку Саши с подтверждённым протоколом docs/06; не удалять правила заказчика из-за нового PDF.
4. **Провайдеры:** рабочий чат — DeepSeek/ReformBoss. В fe348a5 chat endpoint настраивается, embeddings опциональны через full-text fallback. Подтвердить весь live-путь отдельно: сохранённое сравнение RAG содержит четыре provider_network_error.
5. **Хранение:** общий источник для API, CSV и Sheets. В fe348a5 защищённый admin CSV сессий работает; согласовать 18/28/32 колонки и миграцию main SQLite в новый контур.
