# Доступность облачных моделей и переключение (22.10.2026)

Проверка выполнена с ключом и адресом API, уже настроенными в работающем процессе. Скрипт `python -m scripts.probe_provider_health` отправил каждой модели короткий запрос JSON без данных анкет. Ключи и ответы кандидатов в отчёт не включены.

| Модель | Короткий запрос | Строгая классификация тестового поля |
| --- | --- | --- |
| `deepseek-v4.1-flash` | `ok` | Полный прогон харнесса прошёл с 24 полями, без резервной модели |
| `glm-5.3` | `provider_http_401` | Недоступна текущему ключу |
| `kimi-k3` | `ok` | Возвращала пересказ вместо точной цитаты поля; валидатор доказательства отклонил результат |

Короткий запрос проверяет доступность транспорта, а не качество классификации. В полном HTTP-прогоне с подписанным уточнением облачные попытки завершились ошибками, и сохранённую анкету оценивала локальная `qwen-local`. Результат этого прогона и ссылка на единственную синтетическую строку приведены в `docs/20-google-sheets-cloud-http-qa-20261022.md`.

Работающий локальный сервер перезапущен с порядком `deepseek-v4.1-flash` → `kimi-k3` → `qwen-local`; `glm-5.3` исключена из резервного списка из-за HTTP 401. При ошибке валидатора или провайдера адаптер регистрирует только имя модели, безопасный код ошибки и число попыток; сырой текст анкеты в этих записях отсутствует. Результат оценки также содержит `provider_failures`, когда перед ним были неудачные попытки.

Позже отдельный HTTP-прогон **без локальной резервной модели** завершился
с `provider_model=deepseek-v4.1-flash`, записью в SQLite и одной строкой
в Google Sheets; подробности и ссылка на вымышленную строку приведены в
`docs/20-google-sheets-cloud-http-qa-20261022.md`. Это подтверждает
облачный путь для одной анкеты, но не доказывает устойчивую доступность
модели под длительной нагрузкой. Kimi пока непригодна как проверенный
резерв для строгой классификации.

В длительной повторной разметке исторических полей по таксономии `v2`
одна из первых 26 анкет проверила все три ступени переключения вживую:
`deepseek-v4.1-flash` вернула `provider_http_524`, `kimi-k3` —
`invalid_model_json`, `qwen-local` выдала полный набор из семи полей.
В строке очереди сохранены имена попыток и коды без текста ответов;
`review_status=needs_curator_approval`. Это подтверждает переключение
для классификации, но ответ локальной модели тоже требует проверки куратора.
