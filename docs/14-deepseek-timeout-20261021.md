21 октября 2026. Использовались только вымышленные ответы; ключ оставался в памяти процессов, без вывода в терминал и записи в файлы.

## Сравнение среды и требований

Оба прямых запроса выполнены исходным интерпретатором сервера: Python 3.12.10 / OpenSSL 3.0.16, рабочая папка `Desktop/GIM_LIVE`. Переменные proxy отсутствовали. Значения endpoint/model/JSON-режима совпадали. Это контролируемая проверка в исходной среде, а не сравнение запроса на другом компьютере с сервером.

Минимальный запрос: 41 входной токен, 20 токенов генерации (13 reasoning). Полный запрос: 2117 входных токенов, 3266 токенов генерации (1093 reasoning); 3930 символов system и 2921 символ user со схемой/ответами. `max_tokens` и `stream` не задавались, как в приложении. Сырой ответ не сохранялся; проверялся в памяти.

**Непосредственная причина воспроизведённого 503 — наш лимит ожидания 60 с.** Полная генерация с теми же требованиями заняла 93 с и оказалась валидной. Это не HTTP 503 от DeepSeek, не ошибка ключа/TLS и не отказ проверки цитат в этом прогоне. Больший объём генерации и reasoning согласуются с большей задержкой, но эксперимент не измеряет отдельно время очереди и каждую стадию модели. Разброс 50–93 с показывает, почему одного прежнего probe за 37,8 с недостаточно для выбора лимита.

## Исправление

- `start-reformboss.ps1`: `-TimeoutSeconds`, default 180, диапазон 1–300 с; значение передаётся через GIM_LLM_TIMEOUT.
- `scripts/check_reformboss.py`: timeout берётся из той же переменной (default 180); CLI `--timeout` явно переопределяет её. Прежние отдельные hardcoded 60 с убраны.
- Универсальный адаптер сохраняет default 30 с для других способов запуска; для них нужно задать env явно.
- Схема, дословные evidence, запрет выдуманного балла и явный отказ без fallback сохранены.
- Регрессионный тест проверяет default, env и CLI приоритет таймаута пробника.

Проверки: **61 PASS / 1 live SKIP / 0 FAIL** в автономном runner; PowerShell parse PASS; отдельная фактическая live-проверка выше PASS. Пропуск unit live-теста означает отсутствие его opt-in окружения и не отменяет выполненный запрос на работающем сервере.

Таймаут 180 с не гарантирует постоянную доступность провайдера. Четыре экспертных сценария, фактическое время UX и Google Sheets остаются отдельной приёмкой #27/#6.
