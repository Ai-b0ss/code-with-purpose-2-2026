QA-скрипт `four_cases.json` содержит четыре регрессионных профиля и не заменяет прогон 15. Источник каждого правила и неподтверждённые часы фондов разобраны в [сверке](18-criteria-source-audit-20261021.md).

**ВНИМАНИЕ: тестовые персоны и баллы 0–3 в этом документе синтетические, придуманы командой для проверки сценариев. Это НЕ исторические оценки кураторов ГИМ и НЕ подтверждённая музеем калибровочная шкала.** Автоматический отказ и жёсткие пороги из примеров не считать правилами ГИМ без подтверждения эксперта. Для реального оценщика пока использовать `score: null`.

**Назначение:** калибровка промптов ИИ-оценщика ([Issue #5](https://github.com/Ai-b0ss/code-with-purpose-2-2026/issues/5)), проверка валидации формы ([Issue #4](https://github.com/Ai-b0ss/code-with-purpose-2-2026/issues/4)) и сквозное QA-тестирование ([Issue #8](https://github.com/Ai-b0ss/code-with-purpose-2-2026/issues/8)).
