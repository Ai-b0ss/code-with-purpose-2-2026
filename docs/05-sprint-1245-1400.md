## 12:55–13:05 — закрепить контракт, без спора о стеке
**Игорь + Илья.** Договориться об именах полей и одном JSON-сообщении. Пока Сани нет, фронт не ждёт готовый backend. В мок-режиме использует тот же контракт, что будет у настоящего API.

**Вход (пример, всё вымышленное):**
```json
{
  "application_id": "demo-001",
  "age_over_18": true,
  "desired_direction": "media",
  "motivation": "Хочу помогать с образовательным видеоконтентом об истории",
  "experience": "Монтировал ролики для студенческого проекта",
  "availability_hours_month": 16,
  "expectations": "Понимать задачи и иметь обратную связь"
}
```

**Ответ оценщика (предлагаемая минимальная версия):**
```json
{
  "application_id": "demo-001",
  "eligibility": {"age_over_18": true, "requires_human_review": false},
  "fit_to_museum": {"level": "potential", "explanation": "Мотивация и навыки подходят медиа-направлению"},
  "fit_to_candidate": {"level": "potential", "explanation": "Можно предложить задачи по видеоконтенту"},
  "rubric": [
    {"criterion": "motivation", "score": null, "evidence": "Хочу помогать с образовательным видеоконтентом"}
  ],
  "followup_questions": ["Какие форматы вам ближе: короткие ролики, интервью или репортажи?"],
  "interview_questions": ["Расскажите о готовом примере вашего видео"],
  "status": "needs_coordinator_review"
}
```
**Важно:** `score:null` до подтверждения музеем значений и весов; модель не должна выдумывать «официальный балл 0–3». Любой результат — рекомендация с проверкой координатором.
