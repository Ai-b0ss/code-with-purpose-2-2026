## Изменения
В веб-форме добавлены видимый индикатор анализа и статус для вспомогательных технологий. Во время запроса запрещены повторная отправка и переход назад; при ответе, ошибке или новом уточняющем вопросе состояние восстанавливается. Не обещается срок в 2 минуты: два этапа могут потребовать несколько обращений.
В VK бот перед блокирующим запросом сообщает об обработке, не выдавая это за успешную регистрацию. При ошибке финальной отправки показывает кнопку повтора и повторно использует прежний application_id. Не допускается глобальный перехват слова «повтор» из произвольных ответов кандидата, чтобы не обходить этап уточнений. Сохранён существующий HTTP timeout 210 секунд (он уже больше 180 секунд коммита Ильи).
