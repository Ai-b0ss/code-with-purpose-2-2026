# ГИМ — требования к MVP

**Заказчик:** Государственный исторический музей. В папке организаторов — «Кейс 2. ГИМ», на сайте хакатона — кейс №3. Основание: оригинальные документы в [materials/gim](../materials/gim/) и ответы представителя музея, собранные [здесь](06-gim-stakeholder-answers.md).

## Задача

Сократить ручной разбор анкет волонтёров и помочь обеим сторонам: музею — определить подходящие направления и темы очного интервью, кандидату — понять, соответствует ли программа его ожиданиям. Куратор сохраняет окончательное решение.

**Порядок целей заказчика:** (1) качество рекомендаций; (2) близость к историческим оценкам кураторов; (3) прогноз фактической активности.

## Сценарий P0

1. **Кандидат** знакомится с программой и за **5–7 минут** заполняет диалоговую анкету. Число вопросов не фиксировано: коротких ответов может быть больше, открытых — меньше.
2. **Уточнения** появляются только при недостатке конкретики о мотивации, интересах, навыках или реальной возможности уделять время.
3. **Оценщик** возвращает понятное саммари, сильные стороны, возможные проблемы, рекомендуемое музейное направление с аргументацией и вопросы для интервью.
4. **Куратор** получает **одну общую Google-таблицу**: вопросы/ответы, оценка 0–3, саммари, проблемы, рекомендуемое направление; Excel — запасной формат.
5. Кандидаты с высокой нагрузкой (первый курс, полная ставка, другие программы) рассматриваются **индивидуально**: это повод уточнить график, не безусловный отказ.

**Платформа:** VK предпочтителен, но отдельный творческий сайт разрешён; Telegram не подходит по исходному ТЗ.

## Официальная анкета

Ориентироваться на [«Анкета волонтера. Вопросы..docx»](../materials/gim/) и рабочие [«Критерии_отбора_ГИМ.xlsx»](Критерии_отбора_ГИМ.xlsx). Блоки: ФИО и контакты, возраст, учёба/работа, опыт/интересы, мотивация, ожидания, доступность, хобби, желаемое направление, источник информации, контекстные уточнения.

Предусмотрены организационное, проектное, фондовое, инклюзивное и медиа-направление; возможен ответ «ещё не определился».

Пять групп критериев: **мотивация; опыт и навыки; учебная/рабочая нагрузка; полнота анкеты; логистика**. Выводим рабочие приоритеты из оценок кураторов, не выдавая произвольные веса за официальные.

## Исходные данные и оценка качества

В трёх листах анкет за 2024–2025 годы — **206 строк кандидатов, из них 112 с заполненной оценкой 0–3** (первичная проверка файлов). Пустая оценка не равна 0. Кроме баллов, имеются поля о приёме, продолжительности пребывания и активности.

Сначала показываем **полезные рекомендации**, затем проверяем близость оценки к куратору на отложенной части размеченных анкет и анализируем расхождения. Предсказание активности — необязательная исследовательская возможность, не основа MVP.

## Что уже реализовано и чего нет

- **Сделано в `main`:** стартовая форма в 4 шага, простые уточнения по правилам, API FastAPI, SQLite, идемпотентная запись по ID, CSV, модульные и HTTP smoke-тесты.
- **Не сделано:** полный набор музейных вопросов, адаптивные LLM-уточнения, LLM-рекомендации, калиброванная шкала 0–3, прямая интеграция с Google Sheets.
- **Не блокирует MVP:** VK-бот, отдельный кабинет координатора, продвинутая аналитика, собственное обучение ML.

## Критерий готовности

На одном ноутбуке кандидат проходит анкету, получает уместное уточнение, итоговая рекомендация объяснима, анкета **однократно появляется** в Google Sheets с нужными колонками, ошибки и повторная отправка обработаны, а Ева проверила три контрастных пользовательских сценария.

Источник истины по уже действующим адресам API — [инструкция запуска](10-first-run.md). [Текущие задачи](../issues).
