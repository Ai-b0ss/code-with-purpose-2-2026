**Кейс выбран:** Государственный исторический музей. Этот документ описывает конкретную работу, а не предварительную заявку на хакатон.

| Участник | Отвечает за | Проверяемый результат |
| --- | --- | --- |
| **Игорь** — капитан | Продукт, ИИ-оценщик, единый контракт API, интеграция, питч | Ответ оценщика содержит обоснование, направление, вопросы на интервью; общий продукт проходит тест |
| **Илья Соколов** (`f0ut324`) | Пользовательский сайт и диалоговая анкета | Анкета покрывает вопросы музея и заполняется примерно за 5–7 минут |
| **Александр Мирошниченко** (`r0shn1ch`) | Backend, SQLite, Google Sheets, экспорт | Доступ к приватному репозиторию **Write подтверждён**; задачи GitHub **не назначены**, работа по интеграции — после распределения |
| **Ева Шишкина** (`evaskvish`) | Критерии, тестовые случаи, UX, проверка рекомендаций, защита | Есть 8–12 тестовых анкет и протокол «вход → ожидание → результат» |

Разделение кода: Илья — `frontend/index.html`; Саня — слой хранения/экспорта в `backend/`; Игорь — LLM/рубрика, не менять одни и те же функции одновременно. Ева не обязана программировать.

Перед интеграцией сверять [текущее API](10-first-run.md) и [живые задачи](https://github.com/Ai-b0ss/code-with-purpose-2-2026/issues) вместо самостоятельного переизобретения интерфейсов. **PR #13 (оценщик) и PR #14 (локальные тесты) пока не в `main`.** У PR #14 пересекаются файлы с #13; проверить версии перед merge. При смене структуры данных согласовать обновление между Ильёй, Игорем и Саней.

Со слов капитана, прежний GitHub Евы заблокирован; **не назначать Issues на прежний аккаунт** до сообщения нового никнейма. Подготовленная ею рубрика в docs/ сохранена. Согласование и личная приёмка объединённой ветки описаны в [чек-листе](12-acceptance-20261021.md).
