# Протокол исторической проверки

Сначала куратор подтверждает смысл экспертных баллов и допустимость обработки. В заголовке исходных XLSX 0 означает «не позвали на очное собеседование», 1 слабую, 2 среднюю, 3 хорошую анкету. Это смешивает решение и качество. Основной исторический ordinal benchmark обязан явно указать это ограничение. Пустой балл остаётся unknown. Приём и активность имеют отдельные метки и не вычисляются из балла. Шкала приложения gim-five-groups-pilot-v1 пока не утверждена ГИМ.

Импорт: `python -m scripts.import_historical --source "materials/gim/Анкеты 2024 осень.xlsx" --source "materials/gim/Анкеты 2025 весна.xlsx" --dry-run`. Никаких обращений к HTTP. Сводка без строк кандидатов — `qa/historical-import-summary.json`. Для разрешённого локального экспорта добавьте `--include-personal-data`; результат создаётся с правами 0600 в игнорируемом reports/historical-local, без перезаписи существующего файла. На Windows отдельно проверьте ACL каталога. Сырые значения сохраняются только в этом приватном экспорте. Исторические поля не проходят валидацию новой анкеты; отсутствующие мотивация/часы/контакты явно помечены. Год рождения без дня/месяца и артефакт 1900 не становятся полноценной датой.

До анализа holdout выполните `python -m scripts.benchmark_historical --dataset reports/historical-local/dataset.ndjson --split reports/historical-local/split.json --freeze`. Фиксируются хеш датасета и seed gim-holdout-v1. Семантически одинаковые анкеты группируются; группа не может попасть в разные части. Стратификация по исторической метке и сезону, примерно 25% test; группы менее четырёх остаются в tune. Манифест не перезаписывается. Настройки оценщика и критерии приемлемости фиксируются до теста в отдельном утверждённом протоколе. Внешняя LLM автоматически не вызывается.

Predictions — JSON object candidate_id → 0/1/2/3/null, ровно для размеченных test ID. Команда оценки: `python -m scripts.benchmark_historical --dataset … --split … --predictions …`. Отчёт содержит 4×4 confusion matrix, precision/recall/F1, macro-F1 по всем четырём классам (отсутствующий класс даёт 0), MAE по числовым парам, accuracy с null как несовпадением, coverage, null, weighted kappa, ошибки ≥2, bootstrap интервал MAE (1000 повторов, фиксированный seed), отдельные сезоны. Recall учитывает abstention; confusion matrix содержит только числовые пары, её сумма равна numeric_pairs. Baseline majority определяется только по tune, второй baseline всегда 2.

Contract tests проверяют формулы, утечку split и поведение null на синтетике. Они не доказывают точность модели. Реальных предсказаний holdout, независимой разметки Евы и утверждения куратора ещё нет. Порог успешности нельзя выбирать после просмотра теста. Не сообщать качество по направлению/активности без соответствующего gold. Не подменять модель её baseline или историческими коэффициентами Александра.
