# Первый запуск (ГИМ)

**Это минимальный работающий прототип**, а не готовая AI-система. В оценке используется помеченная логика `rules_demo`, **баллы 0–3 не выдумываются**, калибровка по куратору будет подключена позже.

## Запуск

Windows: дважды кликнуть `run.bat`, дождаться строки `Uvicorn running`, открыть http://127.0.0.1:8765

Кроссплатформенно:
```shell
python -m pip install -r requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
```

API: `/docs` (автоматическая Swagger-документация); `GET /api/v1/health`; `POST /api/v1/clarification`; `POST /api/v1/preview`; `POST /api/v1/applications`; `GET /api/v1/applications`; `GET /api/v1/applications/{id}`; `GET /api/v1/export.csv`.

Данные хранятся в `data/gim.sqlite3`; можно изменить путь переменной `GIM_DB_PATH`. Локальный адрес доступен только на ноутбуке, где запущен сервер.

## Работа команды

- Илья: `frontend/index.html`. UI уже обращается к работающему API; улучшать под 5–7 минут и структуру оригинальной анкеты, не переписывая сервер.
- Саня: `backend/app.py`, хранение, API, Google Sheets (следующий этап). Начать с существующего `POST /api/v1/applications` и адаптера экспорта; не ломать контракт без согласования.
- Игорь: заменить `evaluate_demo()` полноценным LLM-оценщиком, добавить валидируемую схему и откалибровать по историческим кураторским баллам. Демо-режим оставить в резерве.
- Ева: прогнать 3 сценария; проверить 5–7 минут, корректность уточнений, саммари, причину направления и выгрузку. На текущем этапе все поля старой анкеты ещё не покрыты, зафиксировать разрыв с исходным ТЗ.

## Проверка «работает»

Запустить тест:
```shell
python -m unittest discover -s tests -v
```

После запуска вручную заполнить вымышленную анкету и скачать CSV. Повторить отправку с тем же ID и проверить отсутствие дублей. **Прямой записи в Google Sheets пока нет**, CSV — рабочий резерв.

## Ближайшие задачи

1. UI довести до всех необходимых вопросов анкеты, замерить 5–7 минут.
2. Ввести реальный LLM-слой и версионируемую рубрику (приоритеты из решений кураторов).
3. Подключить Google Sheets adapter по уже созданному шаблону.
4. Сделать измерения качества на отложенной части размеченных исторических анкет.
