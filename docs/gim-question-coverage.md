# Покрытие исходной анкеты ГИМ

Источник: materials/gim/Анкета волонтера. Вопросы..docx, blob 59fec6a11cc774ab902cceb4cd31a9922ee148f1. Смысл и варианты извлечены из word/document.xml исходного DOCX. Нумерация ниже — 19 групп в порядке исходника. Он помечает вопросы обязательными; «если имеется» у опыта означает допустимость ответа «нет», а не необходимость выдумать опыт.

Общая серверная проверка: backend/app.py::validate_submission на clarification, preview, applications до оценщика/резервирования/SQLite/Sheets. Старые записи читаются без новой валидации. Везде используется ApplicationInput, JSON payload SQLite, одна проекция sheet_values и 43 фиксированные колонки. Номера столбцов ниже с единицы. Веб frontend/index.html использует одноимённые id/name, VK — vk_bot/bot.py, указаны состояния.
