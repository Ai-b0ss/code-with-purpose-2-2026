## Порядок работы

1. Прослушать презентацию и зафиксировать факты, ограничения, сроки и критерии сдачи.
2. Сравнить четыре кейса. Не превращать первоначальные предпочтения в уже принятое решение.
3. Выбрать кейс совместно и утвердить минимальный сквозной пользовательский сценарий.
4. Согласовать стек, роли, задачи и критерии приёмки, затем приступить к разработке.
5. Сохранять решения и ссылаться на проверяемые результаты.

## Безопасность

Не коммитить пароли, токены, реальные персональные данные кандидатов и закрытые материалы заказчиков. Не публиковать репозиторий до отдельного решения команды.
