# Код со смыслом 2 · Mission Control

**21–22 октября 2026 · команда из четырёх участников · выбран кейс ГИМ (№3 по нумерации сайта, второй в порядке выступлений).**

Этот приватный репозиторий — отдельное рабочее пространство хакатона. Он **не связан с TravelTech**. Кейс утверждён командой 21.10.2026: **Государственный исторический музей (ГИМ), отбор волонтёров**. Не путать с TravelTech и другими кейсами. Спецификации из защищённой папки ВШЭ проверяются отдельно; чувствительные данные в репозиторий не переносить.

## Порядок работы

1. Выбор сделан: **ГИМ**.
2. Получить и проверить исходное ТЗ из защищённой папки организаторов; отдельно зафиксировать обязательные функции и доступы VK.
3. Утвердить один минимальный сквозной сценарий: анкета → уточнение → оценка по рубрике → разбор координатором.
4. Согласовать контракт API, роли, задачи и критерии приёмки, затем построить вертикальный срез.
5. Перед защитой зафиксировать код, проверить демо и подготовить резервный сценарий.

## Система задач

Пока доступны [Issues](../../issues) и шаблон задачи. [Доска GitHub Projects](https://github.com/users/Ai-b0ss/projects/1) создана и связана с репозиторием. В GitHub Issues созданы задачи UI, AI-оценщика, backend, панели координатора, QA и интеграции. Для демо использовать только синтетические данные. Статусы: Todo → In Progress → Done. Поля Priority и Phase добавлены, их значения уточняются после выбора кейса.

## Безопасность

Организатор разрешил перенести закрытые материалы ГИМ, включая исторические анкеты, в **приватный** командный GitHub — они находятся в `materials/gim/`. **Не публиковать репозиторий** и не выводить эти персональные данные в логи, демонстрации, публичные скриншоты либо внешние LLM/API без отдельного согласования. Не коммитить пароли или токены.
