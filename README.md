Этот приватный репозиторий — отдельное рабочее пространство хакатона. Он **не связан с TravelTech**. Кейс утверждён командой 21.10.2026: **Государственный исторический музей (ГИМ), отбор волонтёров**. Не путать с TravelTech и другими кейсами. Спецификации из защищённой папки ВШЭ проверяются отдельно; чувствительные данные в репозиторий не переносить.

## Порядок работы

1. Выбор сделан: **ГИМ**.
2. Получить и проверить исходное ТЗ из защищённой папки организаторов; отдельно зафиксировать обязательные функции и доступы VK.
3. Утвердить один минимальный сквозной сценарий: анкета → уточнение → оценка по рубрике → разбор координатором.
4. Согласовать контракт API, роли, задачи и критерии приёмки, затем построить вертикальный срез.
5. Перед защитой зафиксировать код, проверить демо и подготовить резервный сценарий.

## Безопасность

Не коммитить пароли, токены, реальные персональные данные кандидатов и закрытые материалы заказчиков. Не публиковать репозиторий до отдельного решения команды.
