# Музейный компас: GraphRAG для анкет волонтёров ГИМ

Анкета собирает ответы по `docs/volunteer-questionnaire.docx`, запрашивает пропущенные поля и только после этого запускает оценку. Согласие и возраст 18+ проверяются алгоритмически. Для остальных кандидатов LangGraph последовательно вызывает Neo4j GraphRAG, модель, проверку цитат, расчёт балла и маршрутизацию. Координатор видит обоснование, уточняющие вопросы и историю пересмотров.

## Запуск в PowerShell

Нужны Python 3.12+ и Docker Desktop. Проект запускает собственный Compose-проект `gim-graphrag` с Neo4j на `127.0.0.1:17474` (Bolt `17687`) и PostgreSQL на `127.0.0.1:15432`; контейнеры других проектов не используются.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` задайте `GIM_COORDINATOR_TOKEN` для панели координатора. Локальная модель использует официальный `/api/chat` Ollama из примера без ключа; этот API позволяет отключить длительное внутреннее рассуждение для оценки анкеты. Для продакшен-модели задайте её `GIM_LLM_ENDPOINT`, `GIM_LLM_API_KEY`, `GIM_LLM_MODEL`; для OpenAI укажите адрес Chat Completions и `OPENAI_API_KEY`. `OPENAI_API_KEY` дополнительно включает векторный поиск. Без него RAG использует полнотекстовый индекс Neo4j и связи графа.

```powershell
.\start-scoring.ps1
```

Сайт и вход студента: `http://127.0.0.1:8765/student`; вход куратора: `http://127.0.0.1:8765/coordinator`. Главная страница также ведёт к обоим входам. Куратор вводит токен и видит ответы текущей анкеты, контакты, балл, рекомендации, микроанализ кандидата и макроанализ потока заявок. Сводка строится по текущим анкетам с действующим согласием.

Скрипт загружает факты, нормализует и дедуплицирует таблицы, отделяет тестовые анкеты, при наличии ключа строит эмбеддинги и запускает API. Сессии, контакты, ревизии и результаты сайт хранит в локальном PostgreSQL; контакты находятся в отдельной схеме `pii`. `-SkipProbe` пропускает пробную оценку. Без ключа модели можно проверить код и граф, но рабочая оценка не вызовется.

Для локальной модели проект использует отдельный контейнер Ollama с NVIDIA GPU: `docker exec gim-graphrag-ollama ollama pull qwen3:14b`. Настройки совместимого API приведены в `.env.example`. После запуска `docker exec gim-graphrag-ollama ollama ps` должен показывать `100% GPU`; 14B проверена на RTX 5070 Ti Laptop с контекстом 8192. Парное сравнение одной модели с GraphRAG и без него запускается командой `.\.venv\Scripts\python.exe -m evaluation.compare_local_rag` и записывает `evaluation/local-rag-comparison.json`. Это измерительный прогон; рабочая цепочка RAG остаётся на Neo4j GraphRAG и LangGraph.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Если локальный Neo4j запущен и загружен, можно повторить проверку с настоящим поиском по графу и сохранённым ответом модели через фиктивный HTTP-ключ:

```powershell
$env:GIM_TEST_LIVE_GRAPH = '1'
$env:GIM_DATABASE_URL = 'postgresql://gim:gim-local-db-2026@127.0.0.1:15432/gim'
.\.venv\Scripts\python.exe -m pytest -q tests/test_dev_model_probe.py
Remove-Item Env:GIM_TEST_LIVE_GRAPH
Remove-Item Env:GIM_DATABASE_URL
```

Если старое окно PowerShell неверно показывает кириллицу, выполните `. .\console-utf8.ps1`. Настройка для новых окон записана в пользовательский профиль PowerShell.

## Данные и решение

Из 168 строк таблиц после удаления 55 копий осталось 113 уникальных анкет: 90 в графе и 23 в отложенной проверочной части. Исторические анкеты загружаются после предоставленного согласия; прямые идентификаторы исключены из поискового текста. В Neo4j также находятся 36 фактов из документов, включая новый `docs/case.txt` и упоминание совмещения волонтёрства с работой. Работа требует уточнения графика, но не является автоматическим отказом.

Порог 2 из 3 и сравнение с минимум пятью анкетами одной рубрики являются пилотной маршрутизацией, а решение о собеседовании и приёме принимает координатор. Если модель не может обосновать один из критериев, балл остаётся пустым и анкета требует проверки. Во время разработки сохранён реальный ответ текущего ассистента на синтетическую анкету; тест пропускает его через локальный HTTP endpoint с фиктивным ключом и полный путь сессии. Этот endpoint и Codex CLI не входят в серверный пайплайн.
