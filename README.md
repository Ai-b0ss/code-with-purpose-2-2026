# Музейный компас — ГИМ

**Хакатон ВШЭ «Код со смыслом 2» · 21–22 октября 2026 · Государственный исторический музей**

Веб-анкета для кандидатов в волонтёры ГИМ: вопросы и уточнения → сохранение ответов → объяснимая предварительная рекомендация → выгрузка данных для координатора. Целевое время заполнения — **5–7 минут**, реальный замер командой ещё нужен.

## Проверенная версия

Совместная сборка [PR #16](https://github.com/Ai-b0ss/code-with-purpose-2-2026/pull/16) включает полную форму Ильи (ветка `feature/issue-4-full-form`), отдельный LLM-оценщик Codex (#13), локальный тестировщик Antigravity (#14) и исправления совместимости. Эта версия принята капитаном после точечных исправлений и проверки.

| FastAPI, SQLite, создание/получение/повторная отправка заявки | **Работает**, прогнано через браузер и настоящий HTTP |

Это не подтверждает качество реальных LLM-рекомендаций, работу Sheets или время заполнения 5–7 минут.

## Запуск ReformBoss (настоящая LLM)

Добавлен [`start-reformboss.ps1`](start-reformboss.ps1): по умолчанию проверяет `deepseek-v4.1-flash` через `https://api.reformboss.com/v1/chat/completions` на вымышленном кандидате, затем поднимает приложение в режиме `llm`. Ключ запрашивается **видимым вводом** (не показывайте экран во время ввода) и не записывается на диск.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-reformboss.ps1
```

`-SkipProbe` — запустить без повторного LLM-пробника; `-Port 8766` — выбрать желаемый начальный порт (по умолчанию 8765 с автопереходом на следующий свободный); `-Model glm-5.3` — переключить модель; `-Compare` — три реальные API-вызова для DeepSeek, GLM и Kimi; `-DisableJsonMode` — обход несовместимого `response_format`. Живой запрос к `deepseek-v4.1-flash` **успешен (37,8 с; валидный JSON, 12 evidence, score=null и риск первого курса отражён)**. Старый порт `8765` оказался занят; [PR #26](https://github.com/Ai-b0ss/code-with-purpose-2-2026/pull/26) добавил автоматический поиск свободного порта. Чтобы не повторять долгий вызов при запуске, используйте `-SkipProbe`. [Инструкция](docs/11-llm-evaluator.md).

## Запуск на своём ноутбуке

Нужны Git и Python 3.11+.

```powershell
git clone https://github.com/Ai-b0ss/code-with-purpose-2-2026.git
cd code-with-purpose-2-2026
python -m pip install -r requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
```

На Windows можно запустить `run.bat`. Откройте **http://127.0.0.1:8765** *на том же компьютере*. Установка и запуск тестов одной командой в Windows — `run-tests.bat`. Эти тесты не требуют GitHub Actions или платных ключей.

**По умолчанию `rules_demo`.** Чтобы попробовать настоящую совместимую LLM, нужно отдельно настроить `GIM_EVALUATION_MODE=llm`, `GIM_LLM_ENDPOINT` (полный URL `/v1/chat/completions`) и `GIM_LLM_MODEL`; ключ `GIM_LLM_API_KEY` необязателен для локальной модели. Ненастроенную модель не считать активной. [Подробная настройка](docs/11-llm-evaluator.md).
