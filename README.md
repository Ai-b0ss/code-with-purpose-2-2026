# Музейный компас — ГИМ

**«Код со смыслом 2» · 21–22 октября 2026 · Государственный исторический музей**

Веб-сервис для отбора волонтёров: кандидат за **5–7 минут** отвечает на вопросы, система уточняет важные детали и формирует понятную рекомендацию, а координатор получает ответы, саммари и рекомендации в одной таблице.

**Заказчик подтвердил:** качество рекомендаций важнее совпадения с историческими оценками; прогноз активности — следующий приоритет. **VK предпочтителен, но сайт допустим.** Основной рабочий формат координатора — **Google Sheets**, Excel подходит как резерв.

## Статус продукта

| Функция | Статус |
| --- | --- |
| Веб-анкета с четырьмя шагами | Работает как первоначальный прототип; не вся анкета музея перенесена |
| Уточнения | Работают на демонстрационных правилах, **не на LLM** |
| FastAPI, SQLite, получение и сохранение заявок | Работают |
| Повторная отправка с тем же ID без дубля | Реализована и проверена |
| Экспорт CSV | Работает; формат требует сверки с Google Sheets |
| Полноценный LLM-оценщик и калиброванный балл 0–3 | **В разработке** — текущая функция `evaluate_demo` не является моделью музея |
| Автоматическая запись в Google Sheets | **Не подключена**; [таблица-шаблон](https://docs.google.com/spreadsheets/d/1AJVzUTu8KJPfknSgQBem5InL3q_ynAQ3qSO2h8bDVSc/edit) создана |
| Интеграция с VK | Не начата, не блокирует основной сценарий |

Первый каркас слит через [PR #11](https://github.com/Ai-b0ss/code-with-purpose-2-2026/pull/11). Пять модульных тестов и локальная HTTP-проверка прошли на Windows 21 октября. Реальный пользовательский прогон на ноутбуке команды ещё предстоит.

## Запуск на любом ноутбуке

Понадобятся Git и Python (рекомендуется 3.11+). Сначала клонируйте этот приватный репозиторий:

```bash
git clone https://github.com/Ai-b0ss/code-with-purpose-2-2026.git
cd code-with-purpose-2-2026
python -m pip install -r requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
```

На Windows можно вместо последних двух команд запустить **`run.bat`**. Откройте **http://127.0.0.1:8765** на **том же ноутбуке**, где работает сервер.

Проверка: `python -m unittest discover -s tests -v`. API доступен по `http://127.0.0.1:8765/docs`. Подробности — в [инструкции запуска](docs/10-first-run.md).
