# Музейный компас — графовый RAG для анкет волонтёров ГИМ

Сайт принимает анкету, хранит контакты отдельно от ответов, ищет релевантные факты в Neo4j и передаёт их вместе с ответами модели. Модель выставляет шесть оценок с цитатами из ответов; сервер проверяет цитаты и считает итоговый балл. Решение о приглашении остаётся за координатором.

## Запуск в PowerShell

Нужны Python 3.12+ и Docker Desktop. Neo4j запускается отдельным Compose-проектом `gim-graphrag` и не использует контейнеры других проектов.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` замените `replace-with-your-real-key` на настоящий `OPENAI_API_KEY`. Затем:

```powershell
.\start-scoring.ps1
```

Сайт: `http://127.0.0.1:8765`. Neo4j Browser: `http://127.0.0.1:17474`, пользователь `neo4j`, пароль для локального контейнера указан в `compose.graphrag.yaml`. Bolt доступен только локально на порту `17687`. Данные Neo4j лежат в отдельном томе `gim-graphrag_gim_neo4j_data`.

Анкета работает через `POST /api/v1/sessions`, `POST /api/v1/sessions/{id}/answers`, `POST /api/v1/sessions/{id}/submit` и `GET /api/v1/sessions/{id}/result`. При правке ответа создаётся новая ревизия и новый запуск оценки; старый результат остаётся в базе. Контакты сессий хранятся в отдельном локальном SQLite-файле.

Скрипт загружает версионированные правила через стандартный `cypher-shell`, нормализует исторические таблицы, удаляет дубли и отделяет тестовую часть до загрузки в Neo4j. В граф идут только обучающие записи. Затем он создаёт векторы через официальный `OpenAIEmbeddings`, делает пробную оценку и запускает FastAPI. Для запуска без пробной оценки используйте `-SkipProbe`. Без настоящего API-ключа граф и проверки кода доступны, но модель не вызывается и числовой балл не выдаётся.

Проверка без ключа:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Если уже открытая консоль всё ещё неправильно показывает кириллицу, выполните `. .\console-utf8.ps1`. Для новых окон PowerShell настройка записана в профиль пользователя.

Прямые идентификаторы из таблиц не входят в текст поиска. Правила оценки и веса взяты из `pdf_files/03_arch.pdf`; старый ноль означает «не пригласили» и не используется как оценка новой рубрики. Алгоритмический отсев проверяет только согласие и возраст 18+.
