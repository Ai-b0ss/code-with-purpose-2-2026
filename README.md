# Код со смыслом 2 · Mission Control

**21–22 октября 2026 · команда из четырёх участников · выбран кейс ГИМ (№3 по нумерации сайта, второй в порядке выступлений).**

Этот приватный репозиторий — отдельное рабочее пространство хакатона. Он **не связан с TravelTech**. Кейс утверждён командой 21.10.2026: **Государственный исторический музей (ГИМ), отбор волонтёров**. Не путать с TravelTech и другими кейсами. Спецификации из защищённой папки ВШЭ проверяются отдельно; чувствительные данные в репозиторий не переносить.

## Быстрый старт (рабочий код уже в `main`)

Windows: клонировать приватный репозиторий и запустить **`run.bat`**. Затем открыть `http://127.0.0.1:8765`.

Альтернатива:

```bash
python -m pip install -r requirements.txt
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8765
```

**Статус:** сайт + API + SQLite + экспорт CSV работают и прошли тесты; текущая логика рекомендаций помечена `rules_demo`, **LLM и Google Sheets API ещё не подключены**. [Инструкция, точки входа и задачи разработчиков](docs/10-first-run.md). Проверенный каркас был слит из [PR #11](https://github.com/Ai-b0ss/code-with-purpose-2-2026/pull/11). Архитектурный [PR #10](https://github.com/Ai-b0ss/code-with-purpose-2-2026/pull/10) остаётся предложением; его контракт шире фактически реализованного API.

## Порядок работы

1. Выбор сделан: **ГИМ**.
2. Получить и проверить исходное ТЗ из защищённой папки организаторов; отдельно зафиксировать обязательные функции и доступы VK.
3. Утвердить один минимальный сквозной сценарий: анкета → уточнение → оценка по рубрике → разбор координатором.
4. Согласовать контракт API, роли, задачи и критерии приёмки, затем построить вертикальный срез.
5. Перед защитой зафиксировать код, проверить демо и подготовить резервный сценарий.

## Безопасность

Организатор разрешил перенести закрытые материалы ГИМ, включая исторические анкеты, в **приватный** командный GitHub — они находятся в `materials/gim/`. **Не публиковать репозиторий** и не выводить эти персональные данные в логи, демонстрации, публичные скриншоты или несанкционированные сервисы. Организатор также разрешил использование предоставленных данных в LLM (со слов капитана, 21.10.2026), но провайдера и параметры обработки нужно согласовать; минимизировать передачу PII. Не коммитить пароли или токены.
