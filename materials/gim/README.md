# Исходные материалы ГИМ

Оригинальные файлы кейса из защищённой папки организаторов ВШЭ:

- `case-description-2.docx` — постановка задачи;
- `volunteer-questionnaire.docx` — вопросы и критерии;
- `applications-2024-autumn.xlsx` и `applications-2025-spring.xlsx` — исторические анкеты и результаты.

Исторические анкеты содержат персональные данные. После нормализации и дедупликации в GraphRAG загружается только обучающая часть ответов; прямые идентификаторы остаются в исходных файлах. Тестовая часть перечислена в `evaluation/holdout-manifest.json` и исключена из графа.

Текущая схема приложения описана в [архитектуре](../../docs/architecture.md).
