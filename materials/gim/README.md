# Материалы кейса ГИМ (закрытый доступ)

Исходные документы и исторические анкеты из закрытой папки организаторов «Кейс 2. ГИМ».
Капитан подтвердил разрешение организатора на перенос в приватный GitHub 21.10.2026.

**Исторические анкеты могут содержать персональные данные.**
Не публиковать репозиторий. Капитан сообщил 21.10.2026 о разрешении организатора использовать эти данные в LLM; перед обработкой зафиксировать допустимый провайдер и условия хранения, минимизировать PII, не включать реальные сведения в публичные демо, логи или запросы вне согласованного процесса.
Для демонстраций и логирования использовать вымышленные данные. Помнить, что история git сохраняет ранние версии.
