# Исходные материалы ГИМ

Оригинальные файлы кейса из защищённой папки организаторов ВШЭ:

- `Описание кейса 2.docx` — постановка задачи;
- `Анкета волонтера. Вопросы..docx` — вопросы и критерии;
- `Анкеты 2024 осень.xlsx` и `Анкеты 2025 весна.xlsx` — исторические анкеты и результаты.

Организатор разрешил команде перенос исходных материалов в приватный GitHub и использовать их при работе с LLM (сообщение капитана от 21.10.2026).

Актуальное описание продукта — [требования](../../docs/04-gim-requirements.md).

Подсчёт непустых исторических записей 21.10: 57 осенних + 55 весенних = 112, у всех есть старый балл. Ветка Саши добавляет третью весеннюю выгрузку и после дедупликации получает 113 уникальных анкет; этот источник пока не в main. Оригиналы main не переименованы и не удалены. [Аудит источников](../../docs/15-repository-audit-20261021.md).
