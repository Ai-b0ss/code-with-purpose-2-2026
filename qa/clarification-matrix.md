# Матрица уточнений

Версия: текущая реализация PR и source manifest qa/product-source-sha256.txt. Данные синтетические. Проверка контракта не равна проверке содержательности реальной модели. Код ограничивает два раунда и три вопроса; это решение команды, а не правило ГИМ.

| Сценарий | Неопределённость | Ожидаемая тема | Offline | Эксперт / реальная LLM |
|---|---|---|---|---|
| collections | интересующие фонды, альтернативы | коллекции и гибкость | PASS, ветка demo + бюджет | NOT_RUN |
| project | формат проекта | квест / мастер-класс / игра | PASS, ветка demo + бюджет | NOT_RUN |
| organizational | аудитория | предпочитаемые посетители | PASS, ветка demo + бюджет | NOT_RUN |
| media | тип контента | фото / видео / тексты / дизайн | PASS, ветка demo + бюджет | NOT_RUN |
| inclusive | задачи и подготовка | сопровождение, обучение без обязательного стажа | PASS, ветка demo + бюджет | NOT_RUN |
| undecided | направление не выбрано | приоритетные интересы / навыки | PASS, валидный сценарий | NOT_RUN |
| full-time + выходные | регулярные свободные дни подтверждены | не объявлять график невозможным | PASS, availability regressions | NOT_RUN |
| первый курс | опыт и доступность | конкретные навыки; без автоотказа | PASS, availability regressions | NOT_RUN |
| другой музей | совмещение | наличие пересечения графиков | PASS, правила риска | NOT_RUN |
| нет опыта | переносимые навыки / обучение | не выдумывать стаж | PASS, форма и API принимают ответ | NOT_RUN |
| ясная анкета | нет важного пробела | ноль вопросов | PASS, fake provider clear | NOT_RUN |
| «не знаю» / повторы | ответ не снимает риск | остановиться, оставить неопределённость | PASS, два раунда, без повтора | NOT_RUN |

Команды: python -m pytest -q tests/test_agent_clarification.py tests/test_agent_reliability.py tests/test_availability_policy.py tests/test_vk_agent_integration.py. Фактический браузерный demo проверяет media → уточнение → «Пока не знаю» → регистрация. Новая живая серия с изменённым prompt и экспертная оценка ещё не проводились. Длительности offline не используются как доказательство 5–7 минут у человека.
